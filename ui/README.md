# OnyxOS UI

The supplied visual reference defines the intended OnyxOS identity for the Redmi Note 8 Pro:

- black/deep-purple surfaces
- neon violet accent
- onion logo as the primary brand mark
- minimal app drawer and settings
- Tor status presented as a first-class system state
- privacy-focused quick settings
- lock screen and boot branding using the same mark

Assets:

- `ui/branding/onyx-onion.svg` — vector logo derived from the supplied reference
- `ui/reference/onyx-ui-reference.png` — visual reference image supplied for the project

The Android implementation should use these assets as the design direction. The current repository is still a source/build layer rather than a completed SystemUI implementation, so the screenshot should not be interpreted as proof that these screens are already present in a booted build.
