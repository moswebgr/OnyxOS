Core

Built around privacy.

The project separates a common OnyxOS core from device-specific Android integration.

◉

Tor-first networking

Target architecture keeps direct networking blocked until the controlled Tor path is ready.

⌁

Ephemeral sessions

RAM-first sessions are designed to reduce persistent local traces across reboots.

◇

Minimal by default

No Google Mobile Services by default, with a lightweight system and fewer background services.

Design system

Built from the reference.

OnyxOS uses the same visual direction: black backgrounds, neon-violet onion branding, minimal launcher surfaces and visible Tor state.

◉

Tor-only networking

Tor is presented as an always-visible system state rather than a hidden background service.

⌁

Live / ephemeral

Sessions are designed around RAM-first operation, with optional encrypted persistence.

◇

No Google. No trackers.

A minimal AOSP-style base with the privacy-focused system surface shown in the supplied design.

Development

Build from GitHub.

Source integration

OnyxOS includes an Android 14 / begonia manifest plus build and installation documentation. Hardware validation is still required before a production release.

Build guide
repo init -u https://github.com/moswebgr/OnyxOS.git -b main repo sync -j$(nproc) lunch lineage_begonia-userdebug m bacon -j$(nproc)
Installation

Ready the device safely.

Unlock the bootloader using Xiaomi official process, verify the device codename is begonia, use a recovery and firmware combination compatible with the build, then sideload the OnyxOS ZIP. Back up your data first.
