OnyxOS is an open-source Android project designed around privacy, minimalism and fail-closed networking. First target: Xiaomi Redmi Note 8 Pro.

Core

Built around privacy.

The project separates a common OnyxOS core from device-specific Android integration.

◉

Tor-first networking

Target architecture keeps direct networking blocked until the controlled Tor path is ready.

⌁

Ephemeral sessions

RAM-first sessions are designed to reduce persistent local traces across reboots.

◇

Minimal by default

No Google Mobile Services by default, with a lightweight system and fewer background services.

Roadmap

Emulator → begonia → hardware validation

First validate UI, networking and session behavior in an emulator. Then integrate the Redmi Note 8 Pro device layer and test Wi‑Fi, mobile data, Bluetooth, camera, audio, fingerprint and power management on real hardware.
