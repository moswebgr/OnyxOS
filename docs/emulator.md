# Emulator Development

The emulator is the first development target for rapid software validation.

## Testable

- UI/framework changes
- boot behavior
- Tor lifecycle
- network policy
- DNS handling
- session reset behavior

## Physical-device-only validation

Camera, fingerprint, sensors, modem/mobile data, exact Wi-Fi/Bluetooth behavior, power management and vendor graphics require real Redmi Note 8 Pro hardware testing.
